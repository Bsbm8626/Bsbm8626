## 🔭 Qué hago

- **Aplicaciones web con Java:** desarrollo con Java EE, JSF/PrimeFaces, Spring Boot y Vue 3 para el frontend.
- **Sistemas de salud:** experiencia en plataformas hospitalarias, trazabilidad y dispensación de medicamentos, e imagenología (RIS).
- **Integraciones:** conexión de sistemas escritos en distintos lenguajes y plataformas, con APIs, procesos batch y exportación de datos.
- **CRM y ERP:** implementación y automatización de CRM, incluyendo Microsoft Dynamics 365 (campos personalizados, workflows, plugins en C#), Odoo, e integración bidireccional con el ERP Syteline.
- **Infraestructura y despliegue:** trabajo en Linux y contenedores con Docker.
- **Bases de datos:** SQL Server (la que más he trabajado), MariaDB, PostgreSQL y Oracle.
