# Hola, soy Bernabe 👋

Desarrollador Java enfocado en **aplicaciones web empresariales** e **integraciones entre sistemas**. Trabajo en proyectos de salud y en integraciones con CRM y ERP, y colaboro de forma continua con equipos de desarrollo.

## 🔭 Qué hago

- **Aplicaciones web con Java:** desarrollo con Java EE, JSF/PrimeFaces, Spring Boot y Vue 3 para el frontend.
- **Sistemas de salud:** experiencia en plataformas hospitalarias, trazabilidad y dispensación de medicamentos, e imagenología (RIS).
- **Integraciones:** conexión de sistemas escritos en distintos lenguajes y plataformas, con APIs, HL7 v2, FHIR v4, procesos batch y exportación de datos.
- **CRM y ERP:** implementación y automatización de CRM, incluyendo Microsoft Dynamics 365 y Odoo (campos personalizados, workflows, plugins en C#), integración bidireccional con el ERPs.
- **Infraestructura y despliegue:** trabajo en Linux y contenedores con Docker.
- **Bases de datos:** PostgreSQL (la que más he trabajado), MariaDB, MySQL, SQL Server y Oracle.
